# Halloween Registration Page

My second course project during my developer training: a Halloween event registration page built with HTML, CSS and Bootstrap.

## The Assignment

Build a Halloween registration page using HTML, CSS, Bootstrap Grid, Google Fonts and Font Awesome icons.

## Technologies Used

- HTML for the page content and registration fields.
- CSS, included in the HTML file, for the Halloween colour scheme and styling.
- Bootstrap 5.3.3 for the responsive grid, spacing and form controls.
- Google Fonts: Creepster for the Halloween headings.
- Font Awesome 6.5.2 for the icons.
- Flexbox utilities for arranging form fields and ticket prices.

## Features

- A Halloween event introduction with themed typography and icons.
- A responsive two-column layout that stacks on smaller screens.
- Time-slot selection and ticket prices for children, adults and seniors.
- Fields for contact details, group size, costumes and a message.
- A footer with sample contact and social links.

## What I Practised

Building a responsive layout with Bootstrap Grid, styling form controls, combining Google Fonts with Font Awesome icons and using Bootstrap utilities to arrange content.

## How to View

Download the files and open `index.html` in a browser. No installation or build step is required. An internet connection is needed to load Bootstrap, Google Fonts and Font Awesome.

## Project Structure

- `index.html`: the complete page, including its CSS.
- `README.md`: project documentation.

## About This Version

This project is kept as a record of my coursework. The reference to an unavailable background image has been replaced with the existing purple background colour. No JavaScript is used.

This is a static frontend demo. The registration button does not send or store registrations, and there is no backend or payment system. The event details and contact links are sample content for the assignment.
