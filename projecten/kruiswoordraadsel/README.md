# Crossword Puzzle — Bootstrap Grid

My third course project during my developer training: recreating a crossword puzzle layout with HTML, CSS and Bootstrap Grid.

## The Assignment

Build a crossword puzzle using Bootstrap Grid to position the cells.

## Technologies Used

- HTML for the puzzle structure and numbered cells.
- CSS, included in the HTML file, for square cells, borders and black squares.
- Bootstrap 5.3.3 for the container and 12-column grid.

## Features

- A crossword layout with 15 rows and 12 columns.
- Bootstrap `row g-0` classes to remove the gaps between cells.
- Bootstrap `col-1` classes so each cell occupies one of the 12 columns.
- Numbered white cells and black squares.
- Square white cells using CSS `aspect-ratio`.
- A centred puzzle with a maximum width of 468 pixels that fits smaller screens.

## What I Practised

Working with Bootstrap's 12-column grid, arranging repeated elements in rows, controlling spacing and styling a consistent crossword layout with CSS.

## How to View

Download the files and open `index.html` in a browser. An internet connection is required to load Bootstrap from its CDN. No installation or build step is needed.

## Project Structure

- `index.html`: the complete puzzle page, including its CSS.
- `README.md`: project documentation.
- `.gitattributes`: hides automatic language statistics on GitHub.

## About This Version

The original assignment code is preserved as a record of my coursework. This is a static layout exercise: the cells are not editable, and there are no clues, answer validation or game logic. No JavaScript is used.
