# Product Page — Tailwind CSS

My fourth course project during my developer training: building a product page with Tailwind CSS.

## The Assignment

Create a product page and use Tailwind CSS to style it.

## Technologies Used

- HTML for the product content and structure.
- Tailwind CSS, loaded through its CDN script, for styling, layout and spacing.
- Font Awesome 6.5.2 for the advantages and disadvantages icons.
- Flexbox utilities to centre the card and align icons with text.

## Features

- A centred AirPods product card with a local product image.
- A product title, short description, new-product badge and sample price.
- Lists of advantages and disadvantages with coloured icons.
- Rounded corners, shadows and a purchase button with a hover effect.

## What I Practised

Styling a page with Tailwind utility classes, combining spacing, typography and colour utilities, positioning an image and arranging a product card with Flexbox.

## How to View

Download the files and open `index.html` in a browser. An internet connection is needed to load Tailwind CSS and Font Awesome. No installation or build step is required for this coursework version.

## Project Structure

- `index.html`: the complete product page and Tailwind utility classes.
- `airpods.jpeg`: the product image supplied with the project.
- `README.md`: project documentation.

## About This Version

The original assignment files are preserved as a record of my coursework. The page includes Tailwind's CDN script; it has no custom JavaScript or purchase logic. The Buy Now button is a visual demo and does not place an order or process payments.

The product information and price are sample content from the assignment, not a current offer. This is an educational project, not an official Apple website. Product names, trademarks and imagery belong to their respective rights holders.
